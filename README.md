
A handpicked music selection, grown over time, algorithm-free, made for listening
and dancing.

[door.link](https://door.link)



## Structure

Monorepo with bun workspaces.

- `apps/web`: door.link (port 3001).
- `apps/app`: the PWA, app.door.link (port 3000).

`bun run dev` from the root starts both apps.
